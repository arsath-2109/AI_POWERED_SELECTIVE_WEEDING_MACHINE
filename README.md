# AI_POWERED_SELECTIVE_WEEDING_MACHINE # AI Paddy Weed Detection 🌱

An AI-based paddy weed detection project using YOLO Oriented Bounding Boxes (OBB) and Google Colab.

## Features
- YOLO model training
- Paddy field image detection
- Model evaluation
- Detection coordinate export
- Model weight saving

## Launch in Google Colab

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/YOUR_USERNAME/AI-Paddy-Weed-Detection/blob/main/AI_Paddy_Weed_OBB_Using_Your_Dataset.ipynb)

## Requirements
- Google account
- Google Colab
- Paddy weed dataset in the required YOLO OBB format

## How to use
1. Open the notebook in Google Colab.
2. Select a GPU runtime if available.
3. Upload the dataset ZIP when prompted.
4. Run the notebook cells in order.

**Note:** The dataset's class IDs must be verified before interpreting detections as rice or weeds.
